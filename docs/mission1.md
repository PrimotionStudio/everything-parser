Mission 01 — Log Reader
Start here
Objective

Build a Rust program that accepts a file path, reads the file, and counts log levels.

Requirements:

- [x] Create a new Cargo project named rustlog.
- [x] Create logs/sample.log with the sample data above.
- [ ] Read the file from your program.
- [ ] Count total lines.
- [ ] Count INFO, WARNING, ERROR, and CRITICAL entries.
- [ ] Count empty lines.
- [ ] Print the summary.
- [ ] Handle the situation where the file doesn't exist without crashing.
      Restrictions:
- No external crates.
- No AI-generated implementation.
- Don't worry about detecting IP addresses yet.
- Don't worry about making the CLI beautiful.
- Use functions instead of doing everything in main().
