Level 1 — The foundation
Your starting point
Build a basic log reader
rustlog read ./logs/sample.log


It should:
- Accept a file path.
- Open a file.
- Read it line by line.
- Count total lines.
- Count empty lines.
- Count lines containing ERROR, WARNING, and INFO.
- Print a summary.
Rust concepts: String, &str, variables, mutability, loops, conditionals, functions, file handling, error handling, ownership.
